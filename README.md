# Orb_Complete_Template

The complete, canonical ORB: one contract and one cognitive runtime shared by every ORB. Products (Website ORB, POPS, Desktop ORB, and future ORBs) change identity, knowledge, tools, appearance, permissions, and configuration; they do not change this foundation.

## Layout

- `Orb_Vault_Template/` — canonical knowledge package: master seed vault with the locked Core Four v2 extensions, the locked Core Four review-record contract, and the Core Four executive summary. Brought in with its commit history.

Further components (A.I.M.S., TPC, Doctrine v1, Correspondence Engine, MCP tool and API manifests, communications and motion runtimes) are added as the ORB Complete Contract v1.0 identifies the canonical source of each.
